# Roadmap (18-day compressed plan)

- Days 1-2  — Foundation: datasets, threat landscape, eval harness skeleton
- Days 3-5  — Heuristic detector: regex/keyword rules scored against the harness
- Days 6-9  — ML classifier: embeddings/DistilBERT vs heuristics baseline
- Days 10-12 — Service: FastAPI proxy, logging, Streamlit dashboard
- Days 13-16 — Red-team: adaptive attacks, document what breaks the detector
- Days 17-18 — Polish: README, threat model writeup, live demo

Eval harness (precision/recall/FPR) is built Day 1-2 and used every phase after.
